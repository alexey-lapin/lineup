## Fixes (lineup-gateway)

- **streamlink works again.** The 0.6.0 image pinned yt-dlp and streamlink but not their dependencies, and picked up urllib3 2.8.0, which breaks streamlink 8.6.0 on every request (`'Urllib3UtilUrlPercentReOverride' has no attribute 'sub'`). Rules that only use yt-dlp were not affected. streamlink is now 8.6.3, and every package the extractors pull in is pinned in `deploy/gateway-tools-requirements.txt`; the build checks the set and that streamlink can prepare a request.
- **Only standard HLS tags reach players.** The relay passed comments and vendor tags through, and some carry upstream URLs and the viewer's address (Twitch's `#EXT-X-TWITCH-INFO`, ad `#EXT-X-DATERANGE` trackers). Comments, vendor tags, `#EXT-X-DATERANGE` and `#EXT-X-SESSION-DATA` (Twitch puts CDN nodes and the viewer's address there) are now dropped. A vendor tag or session data with a URI (such as an image playlist) is dropped instead of failing the whole stream.

lineup itself is unchanged apart from the version.
