## Upgrade notes

**Hooks are webhooks only.** The built-in Jellyfin hook kind and its 65-minute follow-up refresh are gone; Jellyfin is now a webhook recipe ([docs/deploy.md](https://github.com/alexey-lapin/lineup/blob/main/docs/deploy.md#jellyfin)).

Existing Jellyfin hooks are converted on first start, keeping their API key in an `Authorization` header:

- A hook with a stored task id becomes `POST {jellyfin}/ScheduledTasks/Running/{task id}` and keeps its enabled state.
- A hook **without** a stored task id (the 0.2 default) is converted **disabled**, with `REFRESH_GUIDE_TASK_ID` in its URL, and lineup logs a warning at startup until it is fixed. Look up the task id, then:

  ```sh
  lineup hook edit <id> --url http://jellyfin:8096/ScheduledTasks/Running/<task id>
  lineup hook enable <id>
  ```

CLI: `lineup hook add jellyfin` and `lineup hook add webhook` are replaced by `lineup hook add <name> <url>`; `lineup hook edit` is new. API: `HookConfig` has only the `webhook` kind and deliveries no longer have the `followup` trigger.
