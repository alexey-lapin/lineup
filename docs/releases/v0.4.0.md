## Upgrade notes

**0.4 starts from a new database.** It cannot open a 0.3 database: it refuses to start and leaves the file untouched. Before upgrading, export your playlists (`/p/<slug>.m3u`) and save JSON records of your channels, playlists, guide sources, hooks and settings; then start 0.4 with an empty data volume, set up the integrations, re-import the playlists and add the guide sources and hooks again. Keep the old data volume as a backup: only lineup 0.3 can read it. Step by step: [docs/deploy.md](https://github.com/alexey-lapin/lineup/blob/main/docs/deploy.md#upgrading-from-03).

**iPhone home-screen app:** delete the lineup icon and add it to the Home Screen again, so iOS picks up the new status bar style.

## Integrations

The service addresses moved out of Settings into **Integrations**, one per kind of channel:

- **Acestream**: the engine (required) and acexy (optional, recommended). Without acexy, playlists send players to the engine directly, and health checks are off, because only acexy can tell whether someone is watching. The check schedule moved here from Settings.
- **VK proxy**: its URL.
- **Direct URLs** (formerly `raw`): nothing to set up.

Each address has a Test button and shows the live status of the saved one (engine version, acexy's active streams). An integration whose required URL is blank (the engine for Acestream, the proxy for VK) is off: its channels stay listed with a "not set up" badge, but are left out of playlists and guides, keeping their positions.

## Channel details

Click a channel to see its details: the engine's original name for an Acestream id, and while someone watches through acexy, live peers, speeds and players, read from acexy's session (opening it never starts a stream). The latest check and **Check now** are there too. CLI: `lineup info <channel>`.

## Other changes

- iPhone home-screen app: no more frosted strip over the top, dead area at the bottom, or page dragging when you scroll. The browser layout is unchanged.
- API: `/integrations` routes replace the URL fields of `/settings` and `/settings/test`; `GET /channels/{id}/info` is new. `Channel.stream_url` and `ResolveResponse.stream_url` are null while the integration is not set up (see `configured`). The `raw` source kind is now `direct`. `integration.changed` is a new UI event (not a hook event).
- CLI: `lineup integration ls|show|set|test` and `lineup info` are new; `lineup settings` keeps only `epg_refresh_hours`; `--kind raw` is now `--kind direct`.
