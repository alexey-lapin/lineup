## New

- **A client-only CLI.** Each release now has `lineup-cli-<version>-<target>.tar.gz` for macOS and Linux (x86_64 and arm64): the `lineup` command without `serve`, the server or the web UI (about 8 MB instead of 18). It finds the server as before: `--server`, then `LINEUP_SERVER`, then `server = "…"` in `~/.config/lineup/config.toml`, then `http://127.0.0.1:9300`. The full `lineup-<version>-<target>.tar.gz` archives are unchanged.
- **Homebrew.** `brew install alexey-lapin/tap/lineup` installs the client-only CLI (Apple Silicon and Linux), with shell completions. Stable releases update the formula.
- **lineup-gateway archives.** `lineup-gateway-<version>-<target>.tar.gz` for macOS and Linux; the Linux binaries are static and run on any distribution. Each has an example config, the pinned extractor requirements and a README on installing yt-dlp and streamlink without Docker. The image is unchanged.

## Changes

- **Health is shown in a channel's details only.** The channel list in the web UI no longer has a health badge, and `lineup ls` no longer has a HEALTH column: a stored check can be days old and read as the current state. The channel's details page, `lineup show` (new) and `lineup info` show the latest check and the last conclusive one, each with its time. `lineup ls --health ok|dead` still filters, and the API and JSON output are unchanged.

No upgrade steps: the database, the API and the gateway config are as in 0.6.1.
