## Changes

- **Adding a channel or importing asks for the route.** The web UI no longer preselects the route last used in that browser, or the first one by name: pick one each time. Nothing is kept in the browser's storage for it.
- **Logos from hotlink-protected hosts show in the web UI.** The page no longer sends itself as `Referer` to other sites, so hosts that refuse foreign referrers now serve their logos in the guide search, the channel list, playlists and the edit form. Requests to lineup itself are unchanged.

No upgrade steps: the database, the API and the gateway config are as in 0.7.0.
